# simple-interest-calculator
Description

This project is a simple interest calculator that calculates the interest earned or paid on a principal amount over a specific period of time.

Simple Interest Formula

Simple Interest = (P × R × T) / 100

Where:

P = Principal amount

R = Annual interest rate (%)

T = Time in years

Example

Suppose:

Principal = $1,000

Rate = 5%

Time = 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = $100

Total Amount = $1,100

Features

Calculates simple interest

Uses principal, interest rate, and time

Easy to understand and use
